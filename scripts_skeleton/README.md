
Following the principles in [1], you will write a set of scripts to preprocess and analyse the MEG data collected during the MEG lab. The files in this directory provides a skeleton for you to develope further on during the classes. 

In the first class, everyone should create a folder for their own scripts. This way, we will avoid merge conflicts, should the skeleton scripts get updated. 

Skeleton files will be added as we progess through the analysis steps during the course. 


[1] Marijn van Vliet (2020) *Seven quick tips for analysis scripts in neuroimaging.* PLoS Comput Biol 16(3): e1007358. https://doi.org/10.1371/journal.pcbi.1007358
